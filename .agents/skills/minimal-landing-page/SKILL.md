# Minimal Landing Page Design System

## Core Aesthetic Philosophy

**Less is more.** Every element must justify its existence.
The output should look like it was designed by a senior designer at Linear, Vercel, or Notion — not generated by AI.

---

## Typography

- **Primary font**: `Inter` (from Google Fonts)
- **Scale**:
  - Hero h1: `clamp(2.5rem, 5vw, 4.5rem)` — tight `letter-spacing: -0.03em`
  - Section h2: `clamp(1.75rem, 3vw, 2.75rem)` — `letter-spacing: -0.02em`
  - Body: `1rem / 1.625` line-height
  - Labels/captions: `0.75rem`, `font-weight: 500`, `letter-spacing: 0.06em`, UPPERCASE
- **Rule**: Never mix more than 2 font weights in a single section

---

## Color Palette — pick ONE per project

### Dark Premium (default)
- Background: #0A0A0A
- Surface: #141414
- Border: rgba(255,255,255,0.08)
- Text primary: #F5F5F5
- Text muted: #888888
- Accent: White or single brand color

### Light Minimal
- Background: #FFFFFF or #FAFAFA
- Surface: #F5F5F5
- Border: #E5E7EB
- Text primary: #0F172A
- Text muted: #6B7280
- Accent: #0F172A

**Rules**:
- Max 2 colors per section
- NO gradients except as very subtle background wash (opacity: 0.04)
- NO rainbow, neon, glow, or pulsating effects

---

## Spacing (8px grid)

- Section: `py-24` to `py-32`
- Container: `max-w-6xl mx-auto px-6`
- Card gap: `gap-6` or `gap-8`
- Headline → body: `mt-6`
- Body → CTA: `mt-10`

---

## Component Patterns

### Hero
- Eyebrow label (small caps) → H1 → Subtitle → CTAs (Primary + Ghost side-by-side)
- NO stock photos, NO carousels, NO video backgrounds

### Features
- 3-column grid of cards: Icon → Title → 2-line description
- 1px border, max shadow-sm

### Testimonials
- 3-up grid: Quote → Name → Role — nothing more

### Footer CTA
- Inverted dark band, single headline → single button, clean link list

---

## Strict Anti-Patterns — NEVER USE

- animate-pulse / animate-bounce / animate-ping on content
- Multi-direction or rainbow gradients
- Blobs, morphing shapes, particle effects
- Glassmorphism on every card
- More than 3 font sizes per section
- overflow:hidden on parent sections
- <script> tags or external JS
- Lorem ipsum text — use realistic copy
- Placeholder images (src="placeholder.jpg")
- Emoji in headings or body copy

---

## Tailwind Rules

- Use font-sans, tracking-tight on headings
- Grays: text-slate-* / text-zinc-*
- Dark bg: bg-zinc-950 or bg-neutral-950
- Grid: `grid grid-cols-1 md:grid-cols-3 gap-8`
- Section wrapper: `<section class="py-24 px-6"><div class="max-w-6xl mx-auto">`
- Primary button: `bg-white text-black hover:bg-zinc-100 px-6 py-3 rounded-lg font-medium text-sm`
- Ghost button: `border border-zinc-700 text-zinc-300 hover:bg-zinc-900 px-6 py-3 rounded-lg font-medium text-sm`
